# پایشگر رایگان سانس‌های نمایش کورش

این برنامه هر ۱۰ دقیقه صفحهٔ خرید تیوال را بررسی می‌کند. اجرای اول فقط سانس‌های فعلی را به‌عنوان خط مبنا ذخیره می‌کند؛ پس از آن، برای هر سانس جدید یک اعلان فوری `ntfy` با لینک مستقیم خرید می‌فرستد.

## راه‌اندازی گوشی اندرویدی

1. برنامهٔ رایگان **ntfy** را از Google Play یا F-Droid نصب کنید.
2. داخل برنامه روی `+` بزنید و این Topic را وارد کنید:

   `tiwall-kourosh-7f3c2a946b1d48e5a039f671`

3. روی اشتراک ساخته‌شده نگه دارید و تنظیمات اعلان Priority 5 / Max را باز کنید.
4. صدای بلند دلخواه، لرزش و گزینهٔ عبور از Do Not Disturb را فعال کنید.

Topic بالا یک نام تصادفی و غیرقابل‌حدس است. آن را عمومی نکنید؛ هرکس Topic را بداند می‌تواند برای آن اعلان بفرستد.

## فعال‌سازی روی ویندوز

در PowerShell داخل همین پوشه اجرا کنید:

```powershell
.\.venv\Scripts\python.exe .\watcher.py
.\.venv\Scripts\python.exe .\watcher.py --test-notification
powershell -ExecutionPolicy Bypass -File .\install-task.ps1
```

دستور اول خط مبنا را می‌سازد، دستور دوم یک اعلان آزمایشی می‌فرستد و دستور سوم پایش خودکار ده‌دقیقه‌ای را فعال می‌کند.

رایانه باید روشن و به اینترنت متصل باشد. گزارش اجراها در `watcher.log` و وضعیت سانس‌های دیده‌شده در `state.json` ذخیره می‌شود.

## اجرای ابری با GitHub Actions

1. یک مخزن **Private** در GitHub بسازید و فایل‌های پروژه را در آن قرار دهید.
2. در مخزن به `Settings → Secrets and variables → Actions` بروید.
3. روی `New repository secret` بزنید، نام را `NTFY_TOPIC` بگذارید و Topic خصوصی ntfy را به‌عنوان مقدار وارد کنید.
4. در تب `Actions`، Workflow با نام `Watch Tiwall showtimes` را باز کنید.
5. برای آزمایش، `Run workflow` را بزنید و `Send a test notification` را فعال کنید.

Workflow هر ۳۰ دقیقه اجرا می‌شود. هنگام مشاهدهٔ سانس جدید، اعلان Priority 5 می‌فرستد و شناسهٔ سانس را در `state.json` ثبت می‌کند تا اعلان تکراری ارسال نشود. زمان‌بندی‌های GitHub ممکن است در ساعات شلوغ چند دقیقه تأخیر داشته باشند.
